# Security Policy

**Khaemenes Academy — Public Website**

We want Khaemenes Academy to be a safe and welcoming place for learners, families, educators, and visitors. Thank you for helping us identify and address security concerns responsibly.

## Reporting a concern

Please **do not** post security vulnerabilities, private student information, passwords, or other sensitive details in public issues, discussions, or pull requests.

If private vulnerability reporting is available, select **Security → Report a vulnerability** on this repository's GitHub page. Otherwise, contact the project maintainers privately to arrange a secure way to submit your report.

When possible, describe what happened, which public page was affected, and how the issue can be reproduced using non-sensitive test information. Do not send information about other people.

## Responsible conduct

Please use only accounts and information you own or are authorized to access. Avoid disruptive testing, attempts to access someone else's data, social engineering, and publication of exploit instructions before the maintainers can investigate.

If you unexpectedly encounter personal information or a sensitive security issue, stop testing and report it privately.

## Privacy and safety

We take the privacy of students and families seriously. Never submit personal educational records or confidential account details through a public repository issue.

Information shown on a public website should not be taken as proof that a particular account or connected service has been securely authenticated or synchronized.

## Scope and updates

This policy applies to the currently maintained public Khaemenes Academy front-door website. Other linked services may have their own security reporting procedures.

Reports will be reviewed as resources permit. This policy does not promise a fixed response time or offer a bug bounty.
