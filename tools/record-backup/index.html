Academy Record Backup

Local-only encrypted preparation · Not a connected Account Cloud

Preparation tool — not activated for production. Select previously exported course or family backup files from the learner's original device. Files stay in this browser while being encrypted. This page does not read localStorage, import records, authenticate learners, or upload anything.

1. Protect existing exports

Use the original Academy Family Backup and each individual course's export tools first. Select those files below. Do not select unrelated files or other learners' records.

Selected files remain unchanged. A single encrypted backup package will be downloaded after integrity verification.

2. Verify or restore an encrypted backup

Use this section to verify the protected file can be opened. After unlocking, each source export can be downloaded individually without changing course records.

Preservation rules: Do not delete originals. Save a second copy of the encrypted file in a separate protected location. Keep the recovery passphrase outside GitHub and separate from the backup. Losing the passphrase means losing access to the backup. A successful download is not proof that Account Cloud storage or a second-device restore has succeeded.
